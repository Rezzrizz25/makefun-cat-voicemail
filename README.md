A make.fun entry for the **Funniest Cat Voicemail Greeting** bounty: one line, 120 characters at most — the funniest voicemail greeting a cat would record.

## The entry

> Hi, you've reached Miso. I'm busy pushing your favourite mug off the table — leave a message after the crash.

(109 characters. Miso is mid-crime: pushing the caller's favourite mug off the table, and the caller has to leave their message after the crash.)

## Run

```sh
node main.ts
```

This writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with in-code gate checks: single line, non-blank, 1–120 characters, plus a read-back verification that the file on disk is byte-identical to the entry.
